# Golden-output gap table

Every `[gap: GAP-NN]` marker in a golden artifact under this directory points
at one row here. Each row is something the chat-app graph
(`examples/chat-app/chat-app.trig`) cannot say today, with the vocabulary
addition that would let a generator produce the line. The table is the input
to M004's vocabulary slice; see [README.md](README.md) for the marking
convention. Rows with Artifact `runtime (ADR-0007)` come from the ADR-0007
spike (section "Vocabulary gaps for S02"): facts the runtime worker needs,
not lines of a golden file, so no golden marker cites them.

IDs are sequential and never reused. The `Status` column says where each row
stands:

| Status | Meaning |
|--------|---------|
| `open` | Not closed yet. A golden row must still be cited by a `[gap: GAP-NN]` marker. |
| `closed (vocabulary)` | Closed by a vocabulary or model addition. The closing terms go in the "Proposed vocabulary addition" cell. |
| `closed (rule)` | Closed by a documented generator or runtime rule that uses only existing graph facts. The rule goes in the "Proposed vocabulary addition" cell. |
| `deferred: <reason>` | Explicitly left open, with the reason. A golden row must still be cited. |

Closed rows stay in the table as history, and no golden marker may cite them:
the lines they covered become `[graph: ...]` markers. Keep the closing note in
the cell short.
