# SemanticSeams: notes for coding agents

The full rules are in [docs/project/principles.md](docs/project/principles.md). Read it
before changing code, along with the ADRs (`docs/adr/`) and the README of the package
you are changing. An accepted ADR wins over the principles page.

## Non-negotiables

- **The model is the source of truth.** No domain literals in code, templates, stubs or
  drafts. If the model lacks a fact, raise it as a backlog or ADR question; do not
  hard-code it.
- **Interpret BPMN and DMN, generate structure** (ADR-0007). Seam predicates live only in
  the seams graph (ADR-0001). IRIs follow ADR-0002.
- **Shapes before generation.** A model that passes the shapes must generate.
- **Same model, same bytes.** Sort every collection; no timestamps or absolute paths in
  output.
- **Never hand-edit generated files:**
  - `examples/**/generated`, every `compose.<environment>.yaml`;
  - the docs reference pages generated by `docs/scripts/generate.py`;
  - goldens, except deliberately, with their markers.

  Change the source and regenerate.
- **`packages/seams`** depends only on rdflib and lxml, is read-only, and is
  pyright-strict. Import only public names across packages.
- **Errors name the fact:** `GeneratorError` or `ResolutionError(subject, predicate,
  detail)`. Write nothing on failure.
- **Templates hold text, not logic.** Compute in `extract`, render in the template.
- **Never skip, mark as expected to fail, or delete a test** to get green.

## Gates

```sh
uv sync --locked --all-packages
uv run ruff check && uv run ruff format --check
uv run pyright
uv run pytest -q
# docs changes:
cd docs && uv run npm run build
# runtime, generator or compose changes (needs Docker):
SEAMS_E2E=1 uv run pytest -q tests/test_tutorial_e2e.py tests/test_expense_e2e.py
```

After touching a generator, a template or `examples/chat-app/chat-app.trig`, regenerate
the committed outputs with the commands in `docs/project/principles.md` ("Gates before
every push"). CI fails if regeneration changes anything uncommitted.

## Where things are

| Path | What |
|---|---|
| `ontology/`, `ontology/shapes/seam-shapes.ttl` | The vocabularies and the seam shapes |
| `packages/seams` | Read-only model library: loading, hashing, typed views |
| `seams_gen` | Generators (htmx, FastAPI, compose); rules in its README |
| `seams_runtime` | Execution: engine, worker, store, policy |
| `viewer` | Read-only model browser |
| `examples/` | The chat app and the expense tutorial's per-chapter checkpoints |
| `docs/backlog.md` | Planned and proposed work, by item ID |
| `docs/research/` | Research notes; records, so add revision notes rather than rewriting |
